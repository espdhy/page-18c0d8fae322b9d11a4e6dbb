猪的SSR 是一份以订阅为核心的机场服务，而不是单独封装的闭源 VPN 安装包。开通后你得到的是可在 Clash、Shadowrocket、v2rayN 等客户端中导入的订阅地址，一次更新即可同步节点列表、分流规则与线路标签。

服务定位很直接：把「能连上、能看懂流量、能在几台常用设备间切换」作为默认体验。普通线路覆盖日常网页与检索；旗舰与团队档位补充原生流媒体解锁、IPLC 游戏向优化以及更高并发。按年付可锁定更低月均成本，适合已经确认使用习惯的用户。

使用场景

跨境学习与远程协作

查阅文献、登录海外课堂或对接境外代码仓库时，把猪的SSR 订阅导入电脑端客户端，用规则模式让国内站点直连、境外站点走代理，减少来回切换系统代理的麻烦。基础版的三设备额度通常够用笔记本加手机。

流媒体与内容平台

旗舰版强调全节点原生流媒体解锁，适合把电视盒子、平板与手机算进同一订阅。播放前建议在客户端里选标注解锁的节点并更新一次订阅，避免缓存旧入口。基础版覆盖基础流媒体，重度追剧更适合旗舰档。

游戏与实时语音

对延迟敏感的对战与语音，优先使用旗舰版 IPLC 专线游戏加速优化节点，或团队版 VIP 高带宽入口。先测延迟再锁定线路，比频繁自动切换更稳。团队版还适合工作室多台主机共用定制路由。

配置流程与操作说明

猪的SSR 的使用路径是纵向五步：选套餐、拿订阅、装客户端、导入更新、选节点连接。按顺序做完即可，不必先理解底层协议名称。

  1. 确认档位与设备数

    先数清要同时在线的手机、电脑与平板。3 台以内看基础版；个人重度流媒体或游戏看旗舰版；多成员或 20 台并发看团队版。流量按自然月计入极速额度，用尽后需等待重置或升级。

  2. 开通并复制订阅地址

    在官网完成对应套餐开通后，进入订阅管理复制通用订阅链接。链接相当于节点清单钥匙，不要发到公开群或截图外传。若怀疑泄露，应立即在用户中心重置，旧地址失效。

  3. 按系统准备客户端

    Windows 常用 Clash Verge 或 v2rayN；macOS 可用 Clash 系客户端；iOS 常用 Shadowrocket 或 Stash；Android 常用 Clash Meta 系列。从系统商店或项目官方发布页安装，再回到本页对照导入说明。

  4. 导入订阅并更新节点

    打开客户端的订阅或配置页，粘贴链接并命名为「猪的SSR」。执行更新，确认节点列表出现地区与线路标签。若更新失败，检查系统时间、剪贴是否完整，以及是否误开了系统全局代理导致更新请求异常。

  5. 选择节点并开启规则模式

    日常建议规则分流：国内直连、境外走代理。网页与检索选负载较低的普通优化节点；影视选带解锁标识的入口；对战游戏选 IPLC 或低延迟专线。连上后用客户端内延迟测试做一次核对即可开始使用。

配置流程的关键不是「装很多软件」，而是「一份订阅 + 一台常用客户端 + 规则模式」。换设备时重复第三、四步即可，不必重新购买。

客户端下载与机场订阅导入

猪的SSR 官方下载指引只覆盖主流开源或商店客户端的导入方式，不捆绑第三方安装器。下列说明用于把机场订阅变成可连接的加速器，而不是另装一套无关浏览器插件。

桌面端

Windows 与 macOS 安装完成后，找到「订阅 / Profiles / 配置」入口，选择从 URL 导入，粘贴猪的SSR 订阅地址并更新。首次启动可先用规则模式，避免所有国内流量被误送出国。需要系统代理权限时，按客户端提示允许即可。

移动端

iOS 在商店获取客户端后，用「从 URL 添加」粘贴订阅；Android 同样在订阅页粘贴。手机建议关闭无必要的全局 VPN 电池优化白名单限制，以免后台断开。同一账号设备数不要超过套餐上限，否则新终端可能无法握手。

导入后的检查项

  • 订阅名称可识别，避免和旧机场配置混用。
  • 节点列表能刷新，地区标签与专线标识可见。
  • 规则模式下国内应用仍可直连。
  • 流量统计与套餐额度对照，异常消耗时先查是否全局模式。

常见问题

猪的SSR 是独立 VPN 应用还是机场订阅？

猪的SSR 是机场订阅服务。你在官网开通套餐后获得订阅链接，再导入 Clash、Shadowrocket、v2rayN 等客户端使用，从而完成梯子网络加速。它不是必须单独安装的品牌闭源 VPN 安装包。

如何从官网完成客户端下载与第一次连接？

先在本页选择套餐并按配置流程复制订阅，再按系统从商店或客户端项目发布页安装软件。打开订阅栏粘贴链接、更新节点，选择规则模式后点连接。完整步骤见「配置流程与操作说明」。

基础版、旗舰版和团队版应该怎么选？

主要看同时在线设备、月流量和线路类型。3 台设备与 100GB、基础流媒体选基础版；5 台设备、300GB、全节点原生解锁与 IPLC 游戏优化选旗舰版；20 台设备、1000GB、VIP 高带宽与定制路由选团队版。年付价格已在各档标明。

支持哪些设备，超限会怎样？

常见 Windows、macOS、iOS、Android 以及可导入订阅的路由环境都可使用。同时在线超过套餐台数时，新设备可能无法建立连接，需要下线闲置终端或升级档位。流量在套餐周期内累计，用尽后加速会暂停直至重置或升级。

流媒体播不了或游戏延迟高怎么办？

先更新订阅，再换带解锁标识的节点；旗舰版与团队版对原生流媒体与专线的说明更完整。游戏请改用 IPLC 或低延迟入口，并关闭会抢占带宽的后台下载。若仍失败，用优先工单（旗舰）或客户经理（团队）说明地区与客户端名称。

订阅链接安全吗，能不能多人共用一条？

订阅等同于账号凭证，只应保存在自己的客户端里。公开张贴会导致他人占用设备数与流量。需要多人使用请选团队版并自行分配终端，而不是把同一链接发到群文件。怀疑泄露时立刻重置订阅。
